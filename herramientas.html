Reproducción

Cómo reproducir el análisis

Todo el análisis se regenera con tres scripts de Python y se publica como sitio estático, sin pasos de compilación. Las versiones usadas fueron Python 3.14.4, pandas, NumPy y SciPy para los datos; Plotly.js 2.35.2 y Leaflet 1.9.4 para las gráficas y el mapa.

Paso 1 · Entorno

Crear un entorno virtual e instalar las tres librerías de cálculo.

python3 -m venv .venv
.venv/bin/pip install pandas numpy scipy

En Windows el intérprete del entorno es .venv\Scripts\python en lugar de .venv/bin/python.

Paso 2 · Regenerar los JSON de data/

Los scripts se ejecutan en orden: el segundo lee data/vac_oleo.json y data/modelo_continuo.json, que produce el primero. El primero deja sus cuatro archivos en scripts/data/; cópialos a data/ antes de continuar. El segundo descarga los 12 ZIP mensuales de la ANP en la carpeta que indiques con --anual si aún no están.

.venv/bin/python scripts/1_preprocesamiento_mapa.py data/2023_01_producao_Terra.csv
.venv/bin/python scripts/2_descriptiva_inferencial.py data/2023_01_producao_Terra.csv --anual datos-anp
.venv/bin/python scripts/3_regresion.py data/2023_01_producao_Terra.csv

Paso 3 · Servir el sitio

Abrir http://localhost:8000/ desde la raíz del repositorio. Debe servirse por HTTP: las páginas leen los JSON con fetch y abrirlas con file:// deja las secciones vacías.

python3 -m http.server 8000

Uso por sección

Qué herramienta alimenta cada página

Scripts, librerías y archivos que producen cada sección del sitio.
Sección Herramienta Uso y salida
Mapa Web Python (pandas) + Leaflet 1.9.4 Agrupa la producción por Estado y dibuja el corredor terrestre. Genera map_data.json y los JSON de la inferencial (vac_oleo.json, vad_dias_produccion.json, modelo_discreto.json, modelo_continuo.json).
Estadística descriptiva pandas, NumPy + scripts/2_descriptiva_inferencial.py Variables, tablas de frecuencia e indicadores. Genera variables_estadistica.json, distribucion_frecuencias.json e indicadores_descriptivos.json.
Estadística inferencial SciPy (binomial, Poisson, normal, χ², t de Student) + scripts/2_descriptiva_inferencial.py Ajuste de modelos, intervalos de confianza y validación anual. Genera inferencial_ampliacion.json y validacion_anual.json.
Regresión NumPy, SciPy + scripts/3_regresion.py Ajusta los cinco modelos simples y el múltiple, calcula R², errores e influencia. Genera regresion.json.
Machine Learning (4.3.2) scikit-learn + Jupyter/Google Colab Entrena Random Forest y Gradient Boosting; genera data/ml_regresion.json y data/ml_clasificacion.json. Los notebooks en Colab permiten reproducir los resultados moviendo los controles.
Todas las páginas JavaScript sin frameworks + Plotly.js 2.35.2 Lee los JSON de data/ y arma tablas, gráficas e interacción en el navegador; Plotly se carga local desde js/plotly.min.js.
