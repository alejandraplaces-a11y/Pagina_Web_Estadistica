Herramientas utilizadas

Lenguaje

Python 3 con pandas, NumPy y SciPy

Procesan el CSV y calculan la estadística descriptiva e inferencial. Los scripts scripts/1_preprocesamiento_mapa.py, scripts/2_descriptiva_inferencial.py y scripts/3_regresion.py generan los JSON de data/.

Lenguaje

JavaScript sin frameworks

Lee los JSON de data/ y arma tablas, gráficas, mapa e interacción de la página.

Gráficas

Gráficas interactivas: histogramas, ajustes de modelos y comparaciones.

Mapa web de la producción por Estado.

Fuente de datos

Fuente de datos

ANP — Dados abertos

«Produção de petróleo e gás natural por poço», archivo 2023_01_producao_Terra.csv (publicado el 13/03/2023). Para la validación anual se usaron los 12 archivos mensuales de 2023.

Abrir la fuente en gov.br/anp

Reproducibilidad

Reproducir el análisis

Desde la raíz del repositorio:

python3 -m venv .venv && .venv/bin/pip install pandas numpy scipy
.venv/bin/python scripts/1_preprocesamiento_mapa.py data/2023_01_producao_Terra.csv
.venv/bin/python scripts/2_descriptiva_inferencial.py data/2023_01_producao_Terra.csv --anual datos_2023/
.venv/bin/python scripts/3_regresion.py data/2023_01_producao_Terra.csv
python3 -m http.server 8000

El último comando sirve el sitio en http://localhost:8000/; abrirlo con file:// no funciona porque las páginas leen JSON locales.
